HAND CRICKET ARENA — UNLIMITED MULTIPLAYER PRO V6

V6 multiplayer updates:
- Mobile-first responsive multiplayer layout.
- Public available-room list with one-click Join.
- No multiplayer room password or capture code.
- Playing format can be 1v1, 1v2, 2v1, ... up to 11v11.
- Maximum 11 playing players per team; room officials do not count toward the 11.
- Custom Team A and Team B names (e.g. RCB vs Punjab).
- Room Creator can assign Match Referee, Commentator and Match Officials.
- Room Creator can assign/change team captains.
- Match Referee controls the toss; Room Creator is the default referee until one is assigned.
- Commentator, referee and officials are non-playing spectators.
- Existing opening sound, toss sound, SIX sequence and wicket sequence retained.

Run locally:
npm install
npm start

Then open http://localhost:3000/
