HAND CRICKET ARENA V13 — UNIQUE GAME ID

Changes:
- Display name and Game ID are now separate.
- Display names may repeat (e.g. two players can both display as Shivam Yadav).
- Game ID must be unique, 3–20 characters: letters, numbers, underscore.

- Server enforces uniqueness case-insensitively, so Shivam07 and shivam07 cannot both exist.
- Login response now returns the saved Game ID.
- Multiplayer continues to use the authenticated Game ID automatically.
