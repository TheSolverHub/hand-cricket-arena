HAND CRICKET ARENA V15 - TEAM VOICE / PERMISSIONS

V15 adds compact team communication and authority controls:
- Team-private text chat: only players on the same team receive it.
- Public text/voice/emoji is restricted to room admin, captains, referee/umpire and officials.
- Voice recording uses the browser microphone via MediaRecorder. Hold the voice button to record and release to send.
- Emoji tap sends public; press-and-hold sends to the user's team. 20 emoji phrases are included and played with browser speech synthesis.
- Captain/admin/umpire can switch the active batter or bowler to an online teammate when a player goes offline.
- If the room admin disconnects, control transfers to an online captain, then referee, then another online player.
- If a captain disconnects, captain assignment can move to another online teammate.
- A disconnected player can reconnect to the same room/account without creating a duplicate player entry.
- Public question tool is available to captain/admin/umpire/official for asking the other team.
- Google sign-in remains a configuration item requiring real OAuth/Firebase credentials; it is not faked.
