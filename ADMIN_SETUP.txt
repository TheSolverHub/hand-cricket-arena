HAND CRICKET ARENA — ADMIN / AUTH SETUP

1) Start locally:
   npm install
   npm start
   Open http://localhost:3000/

2) Admin:
   Set an environment variable named ADMIN_KEY to a strong secret.
   Example (Windows PowerShell):
      $env:ADMIN_KEY="YOUR_SECRET"
      npm start
   Then open:
      http://localhost:3000/admin
   The admin page will ask for the same key.

3) Google Sign-In:
   The UI contains Continue with Google, but real Google account selection requires
   a Google OAuth Client ID, redirect URI, and server-side OAuth callback/session handling.
   Do not put a client secret in the HTML. Configure OAuth on the server before production.

4) Phone login:
   Real OTP requires Firebase Auth or another OTP provider. The current account API
   accepts email/phone + password but does NOT claim phone ownership verification.

5) Game ID:
   New registration asks for a unique 3-20 character Game ID. Multiplayer uses this ID
   automatically; users do not need to type their name again.
