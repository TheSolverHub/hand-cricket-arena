HAND CRICKET ARENA — V12 SCORECARD + TEST MATCH UPGRADE

V12 changes:
1. Live match area now shows recent ball events directly below the main score, e.g. Ball 1.1 — 6 runs. These events are NOT the main scorecard.
2. Separate scorecard now focuses on batting and bowling performance:
   - Batter, runs, balls, 4s, 6s, innings
   - Bowler, wickets, balls, runs conceded
   - Innings summary
3. CSV download exports the performance scorecard and, for Test Match, all four innings totals, follow-on status and result.
4. Test Match supports four innings with a follow-on path when the second-innings side trails by 200+ runs.
5. Test Match 4th innings displays a target; follow-on is recorded in the scorecard/CSV.
6. Player of the Match uses recorded runs, wickets and sixes for the local match.
7. Multiplayer scorecard/CSV also uses player-level batting/bowling summaries instead of a ball-by-ball table as the main scorecard.
8. Existing toss.mp3 behavior remains one-shot: it is not replaced and is stopped after the toss animation lands.

IMPORTANT:
- This V12 is an upgrade of the V11 project. Keep the existing audio/ and audio/commentary/ folders and MP3 files.
- For real Google OAuth / phone OTP, production Firebase/Google credentials and backend configuration are still required.
